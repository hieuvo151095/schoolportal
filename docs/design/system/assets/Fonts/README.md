# Fonts

`Inter-OFL.txt` là giấy phép SIL Open Font License 1.1 đi kèm Inter 4.1. File font nằm ở `fonts/` (`Inter-Regular`, `Inter-Medium`, `Inter-SemiBold`, `Inter-Bold`, `Inter-Black`).

Inter không khai báo Reserved Font Name, dùng miễn phí cho sản phẩm thương mại. Khi dùng, giữ bốn quy tắc:

1. Chỉ lấy font từ nguồn chính thức: GitHub `rsms/inter` (Releases) hoặc Google Fonts. File trong `fonts/` là bản release v4.1 (thư mục `web/`), chưa chỉnh sửa.
2. Mọi nơi chứa file font (DS này, repo web Dashboard) kèm `Inter-OFL.txt`; sản phẩm liệt kê Inter trong trang giấy phép mã nguồn mở.
3. Không sửa file font. Cần cắt bớt ký tự (subset) thì đặt tên font khác, không chứa chữ "Inter".
4. Không bán riêng file font, không đặt tên sản phẩm / tính năng là "Inter".

Không dùng SF Pro, SF Compact, New York: giấy phép của Apple chỉ cho dùng để thiết kế UI cho nền tảng Apple.

Cần Legal xác nhận các quy tắc trên trước khi phát hành.
